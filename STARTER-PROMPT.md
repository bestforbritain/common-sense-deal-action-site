1. Unzip this folder somewhere empty and open Claude Code in it.
2. If you've edited the letters doc since this folder was made, export it again as Markdown and replace `inputs/letters.md`.
3. Paste the prompt below.

```
Read common-sense-deal-action-site-brief.md and inputs/letters.md in full before doing anything. The brief is for a new, standalone site where businesses choose their sector, enter their business postcode, and then email their MP or send a posted letter via Stannp. inputs/letters.md holds the draft letter wording to copy into content/letters/ word for word.

Do Phase 0 only:
1. Work through every check in section 3 and report what you find, with links.
2. Extract the brand from commonsensedeal.com as described, and show me the screenshots and the tokens you'd use.
3. Give me a short build plan and list your questions, including anything in the brief that looks wrong.

Don't write application code yet, and never call Stannp without test mode. Stop when Phase 0 is done and wait for me.
```
